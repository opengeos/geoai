# timeseries module

Time-series analysis utilities for multi-temporal satellite and aerial imagery stacks.

This module provides functions for temporal compositing, spectral index time-series computation, bi-temporal change detection, and temporal summary statistics on aligned GeoTIFF stacks, with optional OmniCloudMask integration for cloud-aware compositing.

See the [Timelapse](examples/timelapse.md) and [Water Dynamics](examples/water_dynamics.md) example notebooks for related multi-temporal workflows.
