K-fold cross-validation¶

geoai.cross_validation runs a training callback for each reproducible fold, stores its results, and pools out-of-fold (OOF) confusion counts. It depends only on NumPy, so it works with custom tree-crown pipelines and different training frameworks. geoai.run_kfold and geoai.compute_fold_indices are also available.

For an executable dataset walkthrough, open the K-fold cross-validation notebook. It uses built-in U-Net training, performance plots, batch inference, and prediction comparisons. Configure your image/mask paths and select a Python environment with the local GeoAI checkout, PyTorch, and segmentation-models-pytorch installed.

import geoai
from pathlib import Path
import json

summary = geoai.train_segmentation_model(
    images_dir="data/img", labels_dir="data/mask", output_dir="runs/landslide_cv",
    architecture="unet", encoder_name="resnet34", encoder_weights="imagenet",
    num_channels=3, num_classes=2, batch_size=4, num_epochs=20,
    learning_rate=0.001, k_folds=5, monitor="val_loss", plot_curves=True,
)

for fold in summary["per_fold"]:
    directory = Path(fold["output_dir"])
    geoai.plot_performance_metrics(str(directory / "training_history.pth"))
    split = json.loads((directory / "split.json").read_text())
    geoai.semantic_segmentation_batch(
        input_dir="data/img", input_files=split["held_out_files"],
        output_dir=fold["prediction_dir"], model_path=fold["model_path"],
        architecture="unet", encoder_name="resnet34", num_channels=3, num_classes=2,
        skip_existing=True,
    )

Every fold initializes a fresh model, trains on K-1 folds, and validates on the remaining fold. K determines the held-out fraction (approximately 1/K): five folds use roughly 80% training / 20% validation, while two folds use 50% / 50%. There is no additional inner holdout, and val_split is ignored in k-fold mode. fold_groups keeps each supplied group in one fold; unequal group sizes can produce unequal tile counts. Directory-format inputs must have matching image/mask stems in sorted order.

Before training each fold, GeoAI prints the tile counts and percentages for training and held-out validation/OOF evaluation. With verbose=True, it also lists every tile's filename and zero-based dataset index under its role, plus site/scene groups when supplied. Each fold's split.json saves the complete image paths, paired mask paths, indices, and optional groups for both sets: fit_* (training) and held_out_* (validation and OOF). After held-out inference, verbose output reports each class's fold OOF metrics and pixel confusion counts. The final summary still pools counts across folds.

monitor="val_loss" minimizes held-out validation loss; monitor="val_iou" maximizes held-out validation IoU and remains the default. The selected criterion also controls early stopping. Each fold's model_selection.json records the criterion, score, and selected epoch; best_model.pth keeps the usual weights format. Choose the criterion before training. Changing it requires a new run; an existing IoU-selected checkpoint cannot be reclassified as loss-selected.

The same held-out fold selects the checkpoint, controls early stopping and the learning-rate scheduler, and supplies OOF predictions. Its images are excluded from weight updates, but the reported OOF metrics are CV validation results, not an independent test of checkpoint selection. Use a separate test dataset for final performance assessment. The manifest records held_out_fold as the validation strategy; single-fold reruns cannot mix results from the previous inner-holdout strategy with this one. Start a new experiment for the new strategy.

Training writes normal GeoAI checkpoints and histories in fold_<i>/, calls semantic_segmentation_batch on only its held-out files, and scores saved masks at native resolution. Binary OOF metrics are under oof.micro.class_1 and oof.macro.class_1; multiclass mode reports one-versus-rest counts for every class. Binary scoring handles both 0/1 GeoTIFF predictions and 0/255 PNG predictions. These differ from training-history metrics averaged over classes. Held-out inference uses GeoAI's standard inference preprocessing; custom training transforms must produce inputs consistent with that inference pipeline.

Without k_folds, the original random-split behavior and None return are preserved. only_fold=0, overwrite=True reruns one compatible fold. Full training state resumption is not supported in CV mode. Fold model paths are returned in summary["per_fold"]; no single deployment model is selected automatically.

Ensemble inference¶

After all folds complete, summary["ensemble_model_paths"] contains each fold's selected checkpoint. Pass that list to either semantic_segmentation or semantic_segmentation_batch to average class probabilities with uniform model weights, then apply argmax or a probability threshold:

geoai.semantic_segmentation_batch(
    input_dir="data/new_images", output_dir="runs/landslide_cv/ensemble_predictions",
    model_path=summary["ensemble_model_paths"],
    architecture="unet", encoder_name="resnet34", num_channels=3, num_classes=2,
    probability_threshold=0.5, raise_on_error=True,
)

This averages probabilities, not logits or thresholded masks. Single checkpoint paths retain their previous behavior. All models must share architecture, channels, classes, and input preprocessing. Models are loaded once and processed sequentially per image batch; GPU memory includes every member's weights.

Partial CV runs return an empty ensemble list until all folds are complete. OOF scoring continues to use only the model that held each image out. Applying the full ensemble to CV training imagery includes models that trained on those images, so those predictions must not replace OOF metrics. Evaluate the ensemble on independent test imagery for an unbiased ensemble assessment.

Batch inference's input_files selects exact files. skip_existing=True reuses known outputs; set it to False to regenerate them. model_kwargs forwards extra architecture parameters. CV enables raise_on_error=True so a failed inference cannot silently produce incomplete OOF results; normal batch inference retains its log-and-continue default.

Connect your training pipeline¶

Keep your image and target lists in a fixed order. The callback receives zero-based fold indices, training indices, validation indices, and a separate output directory. Initialize a fresh model and optimizer for every fold, train on the supplied training indices, and predict each held-out sample once.

from pathlib import Path
from geoai.cross_validation import run_kfold, update_counts, validate_paired_files

images = sorted(Path("data/images").glob("*.tif"))
masks = sorted(Path("data/masks").glob("*.tif"))
validate_paired_files(
    {"images": images, "masks": masks},
    index_fn=lambda path: Path(path).stem,
)

def train_fold(fold_idx, train_indices, val_indices, fold_dir):
    model = fit_model(
        [images[i] for i in train_indices],
        [masks[i] for i in train_indices],
        output_dir=fold_dir,
        seed=42 + fold_idx,
    )
    counts = {}
    for i in val_indices:
        probabilities = predict_mask(model, images[i])
        target = read_mask(masks[i])
        update_counts(counts, probabilities, target, threshold=0.5)
    return {"oof": {"crown_mask": counts}}

summary = run_kfold(
    n_samples=len(images), k=5, seed=42,
    experiment_dir="runs/tree_crowns_cv",
    train_fold=train_fold,
    sample_names=[str(path.resolve()) for path in images],
    metadata={"model": "unet", "threshold": 0.5, "training_seed": 42},
)
print(summary["oof"]["micro"]["crown_mask"])

The default validate_paired_files key is the last underscore-separated token of the stem (image_12.tif pairs with mask_12.tif). Supply an index_fn for your naming convention; duplicate keys and misordered pairs raise errors.

run_kfold orchestrates callbacks. geoai.train_segmentation_model accepts train_indices and val_indices to bypass its internal random split; indices refer to its discovered file lists (sorted for directory input). Both lists must be non-empty, unique, in range, and disjoint. Positions in neither list are excluded from training, allowing an independent held-out fold. Without explicit indices or k_folds, its existing val_split behavior is preserved. A callback must honor the supplied indices instead of making another random train/validation split. For a custom PyTorch loop, create torch.utils.data.Subset objects over separate training and validation dataset views, using augmentation only for the training view. Set framework seeds inside the callback and save checkpoints under fold_dir.

Keep sites or scenes together¶

Pass groups, a list of strings in the same order as the samples, to keep all tiles from a site or source scene in one fold. For example:

    6, k=3, seed=42,
    groups=["site_a", "site_a", "site_b", "site_b", "site_c", "site_c"],
)

run_kfold accepts the same groups argument. Groups are balanced by group count, so folds may have different sample counts. Grouping does not infer spatial separation: choose identifiers that keep neighboring or overlapping imagery together. Splits are not stratified by class.

Pixel and instance metrics¶

update_counts accumulates binary pixel tp, fp, fn, and tn. Supply probabilities, not logits, and targets encoded as 0/1. Targets above 0.5 are positive. Non-finite targets are ignored; use valid to exclude finite nodata or ignore-index pixels. CPU tensors are accepted; detach and move GPU tensors to CPU first. For multiclass masks, accumulate a separate one-versus-rest count dictionary per class.

For delineated tree instances, use integer label rasters with background 0:

    add_counts(instance_counts, instance_counts_from_labels(
        gt_labels, predicted_labels, iou_threshold=0.5,
    ))
# Include in the callback result:
result = {"oof": {"crowns": instance_counts}}

Instance IDs may be non-consecutive. Each object matches at most once; IoU thresholds from 0.5 through 1 are supported. Instance iou is tp / (tp + fp + fn) over objects. mean_matched_iou measures mask overlap over matched objects. This is not COCO average precision or panoptic quality.

Every fold must return the same target names and count fields. Return raw counts, not per-batch averages. NumPy scalar counts and metrics are converted to Python values before validation and persistence; unsupported non-JSON objects still raise an error. The summary reports:

  • Micro: sum the held-out counts across folds, then calculate IoU, precision, recall, F1, and (for instances) mean matched IoU.
  • Macro: average those metrics equally across folds.
  • Fold means: average other numeric callback values, such as best_val_loss.

Metrics with a zero denominator are reported as zero. OOF scoring assumes the callback evaluates precisely its held-out samples. If the same held-out fold also selects checkpoints or hyperparameters, use nested CV or an independent test set when an unbiased final evaluation is required.

Results and individual fold reruns¶

Each experiment writes:

...

The manifest records assignments, optional sample names and groups, metadata, and each completed result. JSON files are replaced atomically. If training fails, completed results remain in the manifest and a stale summary is removed.

To train or retrain a single fold, use only_fold=2 (zero-based). Reusing a non-empty directory requires overwrite=True. Other folds' results are retained only when the entire experiment identity matches: sample count, seed, fold assignments, sample names, groups, and metadata. Record your training recipe, thresholds, and dataset version in metadata, and supply stable, unique sample names. Without those, the runner cannot detect changes to your inputs or model.

Built-in segmentation records custom transforms and losses using qualified callable/type names and recursively serialized configuration, including array and tensor values. Equivalent newly created objects can therefore be reused across processes, while changed configuration is rejected. Use a new experiment when changing callable implementations or other training code: qualified names alone cannot detect source-code changes. Cyclic or unsupported configuration raises an error instead of falling back to an object address.

With only_fold=None, overwrite=True reruns every fold and discards old manifest results. Existing callback artifacts such as checkpoints are not deleted; the callback controls their reuse. Concurrent writes to the same experiment directory are unsupported. Partial summaries report complete=False and list folds_completed; only those folds contribute to the metrics.

API reference¶

Generic k-fold cross-validation with pooled out-of-fold (OOF) metrics.

Provides reproducible folds, callback-based orchestration, and pooled pixel or instance counts. Depends only on NumPy; model training stays in the callback.

How it works:

  • compute_fold_indices shuffles range(n_samples) once with a seed and splits it into K contiguous validation chunks, so folds never overlap and the split is reproducible. Keep your sample list in a fixed (e.g. sorted) order.
  • run_kfold trains one model per fold through your train_fold callback. The callback predicts each held-out sample exactly once and returns raw confusion counts. Counts, not ratios, are stored so they pool exactly.
  • After every fold, the result is written into kfold_manifest.json. That lets only_fold=i retrain a single fold and still produce a full summary from the folds already on disk.
  • The summary reports micro OOF metrics (counts pooled across folds, then scored) and macro OOF metrics (the mean of per-fold scores).

def add_counts(total: dict, counts: dict) -> dict:
    """Add every count in ``counts`` into ``total`` (start with {})."""
    for name, value in counts.items():
        total[name] = total.get(name, 0) + value
    return total

def compute_fold_indices(
    n_samples: int, k: int, seed: int, *, groups: list[str] | None = None
) -> list[dict[str, list[int]]]:
    """Return reproducible train/validation indices covering every sample once.

    Args:
        n_samples: Number of samples in a fixed input order.
        k: Number of folds, between two and the number of samples or groups.
        seed: Seed for NumPy's local random generator.
        groups: Optional site/scene identifiers, one string per sample. All
            samples with the same identifier stay in one validation fold.
            Groups are shuffled and split evenly by group count, not tile count.

    Returns:
        A list of dictionaries with sorted ``train`` and ``val`` indices.
    """
    if isinstance(n_samples, bool) or not isinstance(n_samples, int) or n_samples < 2:
        raise ValueError("n_samples must be an integer >= 2.")
    if isinstance(k, bool) or not isinstance(k, int):
        raise ValueError("k must be an integer.")
    if k < 2:
        raise ValueError("k must be >= 2.")
    if k > n_samples:
        raise ValueError(f"k ({k}) cannot exceed number of samples ({n_samples}).")

    rng = np.random.default_rng(seed)
    if groups is None:
        order = rng.permutation(n_samples)
        fold_val_sets = [list(map(int, chunk)) for chunk in np.array_split(order, k)]
    else:
        if len(groups) != n_samples or any(not isinstance(g, str) for g in groups):
            raise ValueError("groups must contain one string per sample.")
        unique_groups = list(dict.fromkeys(groups))
        if k > len(unique_groups):
            raise ValueError("k cannot exceed the number of distinct groups.")
        fold_val_sets = []
        for chunk in np.array_split(rng.permutation(len(unique_groups)), k):
            held_out = {unique_groups[int(i)] for i in chunk}
            fold_val_sets.append(
                [i for i, group in enumerate(groups) if group in held_out]
            )

    folds: list[dict[str, list[int]]] = []
    for i in range(k):
        val_idx = fold_val_sets[i]
        val_set = set(val_idx)
        train_idx = [int(j) for j in range(n_samples) if j not in val_set]
        folds.append({"train": sorted(train_idx), "val": sorted(val_idx)})
    return folds

def instance_counts_from_labels(
    gt_labels, pred_labels, iou_threshold: float = 0.5
) -> dict:
    """Match predicted instances to ground-truth instances by IoU.

    Both inputs are same-shaped nonnegative integer label arrays (0 =
    background). IDs may be non-consecutive. Each object is matched at most
    once, with IoU >= iou_threshold. Thresholds from 0.5 to 1 are supported;
    exact-0.5 ties are resolved greedily from highest IoU down. The ``iou``
    score derived from these counts measures object detection, not mask IoU.
    """
    if not np.isfinite(iou_threshold) or not 0.5 <= iou_threshold <= 1:
        raise ValueError("iou_threshold must be between 0.5 and 1 inclusive.")
    gt = np.asarray(gt_labels)
    pred = np.asarray(pred_labels)
    if gt.shape != pred.shape:
        raise ValueError(
            f"GT and prediction label shapes differ: {gt.shape} != {pred.shape}."
        )

    for labels in (gt, pred):
        if not np.issubdtype(labels.dtype, np.integer) or np.any(labels < 0):
            raise ValueError("Instance labels must be nonnegative integers.")

    def compact(labels):
        """Map arbitrary positive instance IDs to contiguous count-array indices."""
        ids = np.unique(labels[labels > 0])
        return np.where(labels > 0, np.searchsorted(ids, labels) + 1, 0).ravel(), len(
            ids
        )

    gt, n_gt = compact(gt)
    pred, n_pred = compact(pred)
    if n_gt == 0 or n_pred == 0:
        return {"tp": 0, "fp": n_pred, "fn": n_gt, "matched_iou_sum": 0.0}

    gt_area = np.bincount(gt, minlength=n_gt + 1)
    pred_area = np.bincount(pred, minlength=n_pred + 1)

    # Pairwise intersection counts for pixels where both labels are non-zero.
    fg = (gt > 0) & (pred > 0)
    # Store only overlapping pairs, avoiding a dense objects-by-objects matrix.
    pairs, intersection = np.unique(
        np.column_stack((gt[fg], pred[fg])), axis=0, return_counts=True
    )
    union = gt_area[pairs[:, 0]] + pred_area[pairs[:, 1]] - intersection
    iou = intersection / union

    # Each object may be matched at most once. Assign greedily from the highest
    # IoU down; at threshold >= 0.5 this is optimal and also resolves exact-0.5
    # ties where one prediction overlaps two GT objects (a merge error).
    candidates = np.flatnonzero(iou >= iou_threshold)
    order = candidates[np.argsort(-iou[candidates], kind="stable")]
    used_gt: set[int] = set()
    used_pred: set[int] = set()
    tp = 0
    matched_iou_sum = 0.0
    for k in order:
        g, p = map(int, pairs[k])
        if g in used_gt or p in used_pred:
            continue
        used_gt.add(g)
        used_pred.add(p)
        tp += 1
        matched_iou_sum += float(iou[k])
    fp = n_pred - len(used_pred)
    fn = n_gt - len(used_gt)
    # matched_iou_sum lets folds pool correctly: mean IoU = sum / tp.
    return {"tp": tp, "fp": fp, "fn": fn, "matched_iou_sum": matched_iou_sum}

def metrics_from_counts(counts: dict) -> dict:
    """Score a counts dict: IoU, precision, recall, F1 (and mean matched IoU for instances)."""
    tp = counts.get("tp", 0)
    fp = counts.get("fp", 0)
    fn = counts.get("fn", 0)

    iou = tp / (tp + fp + fn) if (tp + fp + fn) else 0.0
    precision = tp / (tp + fp) if (tp + fp) else 0.0
    recall = tp / (tp + fn) if (tp + fn) else 0.0
    f1 = 2 * precision * recall / (precision + recall) if (precision + recall) else 0.0

    out = {**counts, "iou": iou, "precision": precision, "recall": recall, "f1": f1}
    if "matched_iou_sum" in counts:
        # Mean IoU over matched (true-positive) pairs: the boundary quality of
        # the objects that were detected, which F1 says nothing about.
        out["mean_matched_iou"] = counts["matched_iou_sum"] / tp if tp else 0.0
    return out

def run_kfold(
    n_samples: int,
    k: int,
    seed: int,
    experiment_dir: str | Path,
    train_fold: Callable[[int, list[int], list[int], Path], dict],
    *,
    only_fold: int | None = None,
    sample_names: list[str] | None = None,
    metadata: dict | None = None,
    overwrite: bool = False,
    groups: list[str] | None = None,
) -> dict:
    """Train and evaluate every fold, then write and return the CV summary.

    ``train_fold(fold_idx, train_indices, val_indices, fold_dir)`` must return a
    JSON-serialisable dict with an ``"oof"`` entry: ``{target: counts}``, where
    counts come from ``update_counts`` / ``instance_counts_from_labels`` summed
    over that fold's held-out samples. Other numeric entries (e.g.
    ``best_val_loss``) are averaged across folds in the summary. NumPy scalar
    counts and metrics are converted to Python values before validation/storage.

    ``only_fold`` trains a single fold. Folds that an earlier run already
    finished with the same assignment are kept from the manifest, so the summary
    still covers them. ``sample_names`` (same order as the indices) are recorded
    per fold for auditing. ``metadata`` (e.g. the training recipe) goes into the
    manifest. Restoring results requires identical sample names, groups,
    metadata, and fold assignments. ``overwrite=True`` permits rerunning in a
    non-empty directory; it never authorizes mixing incompatible experiments.
    ``groups`` optionally keeps tiles from the same scene/site together (see
    ``compute_fold_indices``). Set framework seeds yourself, initialize a fresh
    model and optimizer per fold, and evaluate only the supplied held-out indices.
    This utility does not control model training or verify callback predictions.
    Calls sharing an experiment directory must run sequentially.
    """
    folds = compute_fold_indices(n_samples, k, seed, groups=groups)
    if sample_names is not None and (
        len(sample_names) != n_samples
        or any(not isinstance(name, str) for name in sample_names)
        or len(set(sample_names)) != n_samples
    ):
        raise ValueError("sample_names must contain one unique string per sample.")
    if metadata is not None and not isinstance(metadata, dict):
        raise ValueError("metadata must be a dictionary.")
    if only_fold is not None and (
        isinstance(only_fold, bool)
        or not isinstance(only_fold, int)
        or not 0 <= only_fold < k
    ):
        raise ValueError(f"only_fold {only_fold} out of range [0, {k - 1}].")

    experiment_dir = Path(experiment_dir).expanduser().resolve()
    manifest_path = experiment_dir / MANIFEST_NAME
    existing_manifest = _read_json(manifest_path)
    if experiment_dir.exists() and any(experiment_dir.iterdir()) and not overwrite:
        raise FileExistsError(
            f"Experiment dir already exists and is not empty: {experiment_dir}. "
            "Pass overwrite=True to continue."
        )
    # Persist the exact fold assignment for reproducibility / auditing.
    manifest: dict[str, Any] = {
        "schema_version": 1,
        "n_samples": n_samples,
        "folds": k,
        "fold_seed": seed,
        "metadata": metadata or {},
        "sample_names": sample_names,
        "groups": groups,
        "fold_assignment": {},
    }
    for i, fold in enumerate(folds):
        entry: dict[str, Any] = {
            "train_indices": fold["train"],
            "val_indices": fold["val"],
        }
        if sample_names is not None:
            entry["val_samples"] = [sample_names[j] for j in fold["val"]]
        manifest["fold_assignment"][f"fold_{i}"] = entry

    # Round-trip before any writes to validate JSON and compare persisted values.
    manifest = json.loads(json.dumps(manifest, allow_nan=False))
    if only_fold is not None and existing_manifest is not None:
        for key in (
            "schema_version",
            "n_samples",
            "folds",
            "fold_seed",
            "metadata",
            "sample_names",
            "groups",
        ):
            if existing_manifest.get(key) != manifest[key]:
                raise ValueError(
                    f"Cannot reuse results: manifest {key} differs. Use a new experiment_dir."
                )
        old_assignment = {
            name: {key: value for key, value in entry.items() if key != "result"}
            for name, entry in existing_manifest.get("fold_assignment", {}).items()
        }
        if old_assignment != manifest["fold_assignment"]:
            raise ValueError("Cannot reuse results: fold assignments differ.")
        # Keep other folds' finished results when their assignment is unchanged.
        for fold_name, existing_entry in existing_manifest.get(
            "fold_assignment", {}
        ).items():
            if (
                fold_name not in manifest["fold_assignment"]
                or fold_name == f"fold_{only_fold}"
            ):
                continue
            new_entry = manifest["fold_assignment"][fold_name]
            if (
                existing_entry.get("train_indices") == new_entry["train_indices"]
                and existing_entry.get("val_indices") == new_entry["val_indices"]
            ):
                manifest["fold_assignment"][fold_name] = existing_entry

    experiment_dir.mkdir(parents=True, exist_ok=True)
    # An interrupted rerun must not leave a stale successful summary behind.
    (experiment_dir / SUMMARY_NAME).unlink(missing_ok=True)
    _write_json(manifest_path, manifest)
    logger.info("Wrote fold manifest: %s", manifest_path)

    fold_range = range(k) if only_fold is None else [only_fold]
    overall_start = time.monotonic()

    for fold_idx in fold_range:
        fold = folds[fold_idx]
        fold_name = f"fold_{fold_idx}"
        fold_dir = experiment_dir / fold_name
        fold_dir.mkdir(parents=True, exist_ok=True)

        logger.info(
            "Fold %s/%s: %s train, %s validation samples",
            fold_idx + 1,
            k,
            len(fold["train"]),
            len(fold["val"]),
        )

        fold_start = time.monotonic()
        result = train_fold(fold_idx, list(fold["train"]), list(fold["val"]), fold_dir)
        if not isinstance(result, dict) or "oof" not in result:
            raise ValueError(
                f"train_fold must return a dict with an 'oof' entry (fold {fold_idx})."
            )
        if isinstance(result["oof"], dict) and any(
            not isinstance(target, str) for target in result["oof"]
        ):
            raise ValueError("OOF target names must be strings.")
        result = json.loads(
            json.dumps(result, allow_nan=False, default=_numpy_scalar_to_python)
        )
        _validate_oof(result["oof"])
        for entry in manifest["fold_assignment"].values():
            if "result" in entry:
                previous = entry["result"]["oof"]
                if {t: set(c) for t, c in previous.items()} != {
                    t: set(c) for t, c in result["oof"].items()
                }:
                    raise ValueError(
                        "All folds must report the same OOF targets and count names."
                    )
        result = {**result, "minutes": round((time.monotonic() - fold_start) / 60.0, 2)}

        _write_json(
            fold_dir / "oof_metrics.json",
            {
                target: metrics_from_counts(counts)
                for target, counts in result["oof"].items()
            },
        )
        manifest["fold_assignment"][fold_name]["result"] = result
        _write_json(manifest_path, manifest)
        logger.info("Fold %s done in %.1f min", fold_idx, result["minutes"])

    # Cross-validation summary across every fold with a result (trained now or restored).
    completed = [
        (i, manifest["fold_assignment"][f"fold_{i}"]["result"])
        for i in range(k)
        if "result" in manifest["fold_assignment"][f"fold_{i}"]
    ]
    scalar_names = list(
        dict.fromkeys(
            name
            for _, result in completed
            for name, value in result.items()
            if name != "oof"
            and isinstance(value, (int, float))
            and not isinstance(value, bool)
        )
    )
    summary = {
        "folds": k,
        "folds_completed": [i for i, _ in completed],
        "complete": len(completed) == k,
        "oof": summarize_oof([result["oof"] for _, result in completed]),
        "fold_means": {
            name: _mean([r.get(name) for _, r in completed]) for name in scalar_names
        },
        "per_fold": [{"fold": i, **result} for i, result in completed],
        "total_minutes": round((time.monotonic() - overall_start) / 60.0, 2),
    }
    summary_path = experiment_dir / SUMMARY_NAME
    _write_json(summary_path, summary)

    logger.info("Folds completed: %s of %s", summary["folds_completed"], k)
    for target, metrics in summary["oof"]["micro"].items():
        logger.info(
            f"OOF micro {target}: P={metrics['precision']:.6f}, R={metrics['recall']:.6f}, "
            f"IoU={metrics['iou']:.6f}, F1={metrics['f1']:.6f}"
        )
    logger.info("Summary: %s", summary_path)
    return summary

def summarize_oof(fold_oofs: list[dict[str, dict]]) -> dict:
    """Pool per-fold OOF counts ({target: counts}) into micro and macro metrics."""
    targets = list(dict.fromkeys(t for oof in fold_oofs for t in oof))
    micro = {}
    macro = {}
    for target in targets:
        per_fold = [oof[target] for oof in fold_oofs if target in oof]
        pooled: dict = {}
        for counts in per_fold:
            add_counts(pooled, counts)
        micro[target] = metrics_from_counts(pooled)
        scored = [metrics_from_counts(c) for c in per_fold]
        names = ["iou", "precision", "recall", "f1"]
        if "mean_matched_iou" in micro[target]:
            names.append("mean_matched_iou")
        macro[target] = {
            name: float(np.mean([m[name] for m in scored if name in m]))
            for name in names
        }
    return {"micro": micro, "macro": macro}

def update_counts(
    counts: dict, probabilities, targets, threshold: float = 0.5, valid=None
) -> dict:
    """Add the pixel confusion counts of one prediction to ``counts`` (start with {}).

    ``probabilities`` and ``targets`` are same-shaped arrays (numpy or CPU
    tensors). A target counts as positive when > 0.5. Non-finite target pixels,
    and pixels where ``valid`` is non-finite or <= 0.5, are ignored.
    """
    threshold = validate_threshold(threshold)
    probabilities = np.asarray(probabilities)
    pred = probabilities >= threshold
    targets = np.asarray(targets)
    if pred.shape != targets.shape:
        raise ValueError(
            f"Prediction and target shapes differ: {pred.shape} != {targets.shape}."
        )
    true = targets > 0.5
    mask = np.isfinite(targets)
    if valid is not None:
        valid = np.asarray(valid)
        if valid.shape != targets.shape:
            raise ValueError(
                f"Valid-area and target shapes differ: {valid.shape} != {targets.shape}."
            )
        mask &= np.isfinite(valid) & (valid > 0.5)
    if not np.all(np.isfinite(probabilities[mask])):
        raise ValueError("Predictions must be finite on valid pixels.")
    for name, hits in (
        ("tp", mask & pred & true),
        ("fp", mask & pred & ~true),
        ("fn", mask & ~pred & true),
        ("tn", mask & ~pred & ~true),
    ):
        counts[name] = counts.get(name, 0) + int(hits.sum())
    return counts

def validate_paired_files(
    files_by_name: dict[str, list[str | Path]],
    reference: str | None = None,
    index_fn: Callable[[str | Path], str] = sample_index,
) -> None:
    """Check that parallel file lists (e.g. images, masks) pair up position by position.

    Every list must have the same length, the same set of sample keys, and the
    same order as the ``reference`` list (default: the first one). Fold
    indices refer to positions, so a misaligned list silently pairs the wrong
    target with an image.
    """
    if not files_by_name:
        raise ValueError("files_by_name must contain at least one file list.")
    if reference is not None and reference not in files_by_name:
        raise ValueError(f"Unknown reference file list: {reference!r}.")
    indices_by_name = {
        name: [index_fn(path) for path in files]
        for name, files in files_by_name.items()
    }
    counts = {name: len(indices) for name, indices in indices_by_name.items()}
    for name, indices in indices_by_name.items():
        if len(set(indices)) != len(indices):
            raise RuntimeError(
                f"Duplicate sample keys in {name}; use a unique index_fn."
            )
    if len(set(counts.values())) != 1:
        raise RuntimeError(
            "Sample count mismatch across file lists: "
            + ", ".join(f"{name}={count}" for name, count in counts.items())
        )

    reference_name = reference if reference is not None else next(iter(files_by_name))
    reference_indices = indices_by_name[reference_name]
    reference_set = set(reference_indices)
    problems = []
    for name, indices in indices_by_name.items():
        if name == reference_name:
            continue
        index_set = set(indices)
        missing = sorted(reference_set - index_set)
        extra = sorted(index_set - reference_set)
        if missing or extra:
            detail = [name]
            if missing:
                detail.append(f"missing indices {missing}")
            if extra:
                detail.append(f"extra indices {extra}")
            problems.append(": ".join([detail[0], "; ".join(detail[1:])]))
        if indices != reference_indices:
            first_bad = next(
                (
                    i
                    for i, (left, right) in enumerate(zip(reference_indices, indices))
                    if left != right
                ),
                None,
            )
            if first_bad is not None:
                problems.append(
                    f"{name}: first order mismatch at position {first_bad}: "
                    f"{reference_name} index {reference_indices[first_bad]} vs {name} index {indices[first_bad]}"
                )
    if problems:
        raise RuntimeError(
            "File lists are not paired by sample index. " + " | ".join(problems)
        )
